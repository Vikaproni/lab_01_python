## Консольный набор утилит: калькулятор и конвертер (Лабораторная работа 1)

Пакет 'toolkit' реализует калькулятор арифметических выражений и конвертер
величин (длина, масса, температура). Калькулятор считает выражение с помощью обратной польской нотации и стеков. Код
запускается через 'python -m toolkit'.

Возможности

Калькулятор:
- `+` и `-` — сложение и вычитание, включая унарные знаки (`-2`, `1+-2`)
- `*` и `/` — умножение и деление
- `//` и `%` — целочисленное деление и остаток 
- `(` `)` — скобки для изменения порядка действий
- округление чисел до 28 знаков после запятой
- целочисленное деление округляет результат к нулю
- остаток имеет знак делимого

Конвертер:
- длина: `mm`, `cm`, `m`, `km`
- масса: `g`, `kg`
- температура: `c`, `f`, `k`
- регистр единиц не важен (`KG` = `kg`)

Обработка ошибок

- пустое выражение — ошибка
- недопустимый символ — ошибка
- несколько бинарных операторов подряд — ошибка
- два числа подряд без оператора — ошибка
- несколько унарных операторов подряд или унарный оператор перед скобкой — ошибка
- незакрытые скобки — ошибка
- неизвестная единица измерения — ошибка
- перевод между несовместимыми группами единиц (например, `kg` в `m`) — ошибка
- температура ниже абсолютного нуля — ошибка
- нечисловое значение при конвертации — ошибка

Все ошибки наследуются от общего класса `ToolkitError`, поэтому командная
строка перехватывает их одной строкой и печатает сообщение в stderr с
кодом завершения `2`. При успехе код завершения — `0`.

Основные функции

Калькулятор (`calculator.py`, `tokeniz.py`, `validat.py`):
- `tokenizator` — разбивает строку выражения на токены (числа, операторы, скобки)
- `validation` — проверяет корректность введенного выражения
- `unary_digit` — определяет унарные знаки и соединяет их с числом
- `one_step_calculations` — вычисляет заданную операцию
- `tokens_to_rpn` — переводит обычную запись выражения в обратную польскую нотацию
- `calculate_in_rpn` — считает выражение в стеке 
- `finaly_result` — точка входа: строка → токены → проверка → результат

Конвертер (`converter.py`):
- `transformation_float` — превращает строку в число, проверяет корректность
- `converter_lenght` — переводит длину через базовую единицу (м)
- `converter_weight` — переводит массу через базовую единицу (кг)
- `converter_temperature` — переводит температуру через кельвины, проверяет абсолютный ноль
- `convert` — определяет группу единиц и вызывает нужный конвертер

Командная строка (`__main__.py`):
- `beautiful_number` — форматирует число для печати (убирает лишние нули)
- `no_flag` — защищает выражение вроде `-2*-3` от того, чтобы argparse принял его за флаг
- `main` — разбирает аргументы командной строки, вызывает ядро, печатает результат или ошибку

Запуск
```
bash
cd src
python -m toolkit calc "2 + 3 * 4"
python -m toolkit calc "-2*-3"
python -m toolkit convert 1000 --from mm --to m
python -m toolkit convert 0 --from c --to f
python -m toolkit --help
```

Тестирование

Проект использует `pytest`. Запуск тестов из корня проекта (там, где
`pyproject.toml`):

bash
python -m pytest -v

Дополнительная проверка стиля кода:

bash
ruff check .
